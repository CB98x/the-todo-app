A command-line todo app I'm building and rebuilding as part of a 12-week self-study program in software engineering. The same simple problem (add, list, mark done, delete, persist) gets a new version each time I learn a new layer of the stack.


The goal isn't a shippable product. It's depth on the basics — writing code I can explain line by line, and understanding what each abstraction is actually solving.


## Versions


- **[v1-cli](./v1-cli)** — Python CLI app with JSON persistence. Built by hand, no AI code generation. Focus: language fundamentals, error handling, serialization.

- _v2 and beyond_ — planned: tests, refactoring, FastAPI web version, database persistence, containerization, CI/CD.

## Why this exists


I'm an Trine University student majoring in IT, aiming for SWE/DevOps roles at large tech companies. This repo is the slow, deliberate part of getting there.
